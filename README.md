# Rynoxsoft 공식 홈페이지

앱·웹서비스를 소개하는 정적 홈페이지입니다. HTML과 CSS로 구성되며 별도 설치나 빌드가 필요하지 않습니다.

## 로컬 확인

이 폴더에서 `python -m http.server 8080 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:8080`을 엽니다.

## 구성

- `index.html`: 브랜드 소개, 서비스 목록, 블로그, 문의 안내
- `styles.css`: PC·모바일 화면 및 접근성 스타일
- `favicon.svg`: 사이트 아이콘
- `CNAME`: 기존 공식 도메인 설정
- `app-ads.txt`: 기존 광고 판매자 정보

## 서비스 추가

`index.html`의 `products` 안에 `article.product`를 추가합니다. 서비스명, 실제 기능, 이용 링크, 문의처와 해당 서비스의 개인정보처리방침을 각각 확인해 작성합니다.

## 운영 시 주의

국민연금 서비스는 민간 서비스임과 자료 해석 시 주의사항을 유지합니다. 개인정보처리방침은 서비스별로 연결하며 서로 대체하지 않습니다. 첫사랑 이야기의 소개 페이지는 별도 폴더에서 관리하며 이 홈페이지에서 연결하지 않습니다. 도메인과 광고 설정은 변경 없이 유지합니다.

커밋·푸시는 연결된 GitHub 게시 설정에 따라 공개 사이트에 반영될 수 있으므로, 로컬 검토 후 진행합니다.
